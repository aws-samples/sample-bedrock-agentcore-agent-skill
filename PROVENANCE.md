# PROVENANCE

This file records how every authored file in this repository was produced, so the work can be
licensed MIT-0 and audited for clean-room provenance.

## Clean-room method

Each authored file was produced with this loop:

1. Identify candidate sources **only** from the primary-source allow-list below.
2. Live-fetch each candidate URL and confirm it loads and states what we claim.
   - A URL that could not be verified at authoring time is flagged inline as `[unverified: <url>]`
     and mirrored in the "Flagged / unverified" section below.
3. Extract facts and recommendations in our own words. Direct quotes are short and attributed.
4. Attach an inline citation to every recommendation and code snippet.
5. Replace volatile facts (prices, quotas, current model IDs, GA/Preview status) with pointers to
   their live authoritative source rather than copying values.
6. Record the file -> source-URL mapping in the ledger below in the same change.

No pre-existing third-party AgentCore skill or plugin was consulted, copied, paraphrased, or
restructured. Structural/format specifications (Agent Plugins, Agent Skills) were used only to
determine package shape, not domain content.

### Client/tooling documentation (repo docs only)

`README.md` additionally cites the official documentation of the agent clients this skill installs
into, so install paths are accurate: `kiro.dev` (Kiro Powers/Skills), `code.claude.com` and
`docs.claude.com` (Claude Code), `developers.openai.com` (Codex), and `docs.github.com` (GitHub
Copilot).

These are **install/tooling references only** — they are not provenance for any AgentCore, Bedrock,
or Strands technical claim, and they are **not permitted in skill content**. The smoke test enforces
this split: `CLIENT_DOC_HOSTS` are accepted only in repo-level docs, while everything under
`skills/` remains restricted to the primary-source allow-list above.
